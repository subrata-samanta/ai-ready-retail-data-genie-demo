# Raw source data (the landing zone)

Synthetic files for the fictional retailer FreshCart, exactly as its source systems would deliver them.
They are deliberately messy. Generated by `python -m freshcart.generate` with a fixed seed.
What each feed contains and what is wrong with it: [docs/02-source-data.md](../../docs/02-source-data.md).

| Folder | Source system | Format |
|---|---|---|
| `pos/` | Store POS transaction log, one file per month | CSV |
| `ecommerce/` | Online orders, one file per month | NDJSON (one JSON order per line) |
| `erp/` | Product master, merchandise hierarchy, cost history | CSV |
| `stores/` | Store master snapshots and code lookups | CSV |
| `crm/` | Loyalty member extract (synthetic personal data) | CSV |
| `promotions/` | Promotion calendar and promoted items | CSV |
| `finance/` | 4-5-4 fiscal calendar and CAD/USD rates | CSV |
| `inventory/` | Nightly stock snapshots, last 13 weeks | CSV |

All names, emails and numbers are fictional. Emails use the reserved `example.com` domain.
