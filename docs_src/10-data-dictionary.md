# 10 · Data dictionary (gold)

[← 9 · Run it on Databricks](09-run-on-databricks.md) · Next: [11 · Data quality →](11-data-quality.md)

Generated from the contracts in [`contracts/gold/`](../contracts/gold/). These comments are what Genie reads to decide
which table answers a question and which column to use, so they follow two templates:

- **Table comment** = *what one row is* + coverage + *which questions it answers* + what it excludes + units.
- **Column comment** = *what it is in business words* + unit, currency and sign + allowed values or an example + *when to use it*.
